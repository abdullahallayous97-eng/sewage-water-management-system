# برنامج إدارة شبكات الصرف الصحي ومياه الأمطار

هذا المشروع يمثل نموذج أولي لتطبيق سطح مكتب (Desktop Application) تم تصميمه باستخدام Visual Studio وC# مع قاعدة بيانات SQLite لإدارة:

- شبكات الصرف الصحي
- شبكات مياه الأمطار
- المناطق والمناطق التشغيلية
- عمليات التفتيش والصيانة
- التقارير الشهرية والتقارير التشغيلية
- بيانات مستخدم واحد

## التقنيات المستخدمة

- C# / WinForms
- .NET 8
- SQLite
- Visual Studio 2022

## متطلبات التشغيل

- Visual Studio 2022
- .NET 8 SDK
- Windows 10 أو أعلى

## التشغيل

1. افتح ملف الحل في Visual Studio.
2. تأكد من استعادة الحزم NuGet.
3. اضغط على Start للتشغيل.

## هيكل المشروع

- `src/SewageStormwaterManagement` : التطبيق الرئيسي
- `README.md` : توثيق المشروع

## وظائف النظام

- إضافة مناطق وخطوط الصرف الصحي
- إضافة شبكات مياه الأمطار
- تسجيل عمليات التفتيش
- تسجيل الصيانة والإصلاحات
- إنشاء تقارير نصية
- عرض إحصائيات سريعة في لوحة التحكم
